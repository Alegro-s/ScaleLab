# Ограничения и что не проверено

**Не проверено в среде разработки**
- Сборка Docker-образов: Docker Hub недоступен из песочницы. Проверено: `docker compose config`, установка зависимостей по шагам Dockerfile, запуск шлюза в раскладке контейнера (`tsx`, `/app/db`, `/app/demo`).
- Работа с реальной MongoDB: сервер недоступен. Тесты идут на реализации `memory` (тот же интерфейс `NoSql`); адаптер `mongoNoSql` и `db/mongo/init.js` не запускались.

**Функциональные**
- Автопоиск эталона на контрольном наборе (`data/datasets/benchmark`): ошибка масштаба 0,0 % без наклона и ~1 % при повороте кадра на 8°; на реальных снимках с размытым краем возможно до ±1–2 %; результат всегда можно поправить вручную (4 угла).
- Эталон и образец должны быть в одной плоскости; перекос больше порога настроек даёт предупреждение.
- Перетаскивание разделов отчёта мышью не реализовано (включение/выключение есть).
- Сегментация пороговая — это предположение, а не истина; результат нужно проверять глазами.
- «Простой» режим: измерение задаётся таблицей вершин, без рисования мышью (по замыслу).
- Демо-снимки синтетические: открытые микрофотографии с наложенным шахматным эталоном.

**Безопасность**
- Для продакшена обязательно сменить `JWT_SECRET`, `POSTGRES_PASSWORD`; за https включить `COOKIE_SECURE=1`.
