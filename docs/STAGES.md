## Критерии готовности режимов

- «Простой»: у всех элементов `transition-duration: 0s`, `animation-name: none` (проверено в Chromium: 0 из 59 элементов с переходами).
- «Новый»: у интерактивных элементов есть переходы (24 из 93), переключение через View Transitions; при `prefers-reduced-motion` анимации отключаются.
