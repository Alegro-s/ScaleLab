# МасштабЛаб Mobile

Android-клиент на Flutter. Делает две вещи: составляет отчёт по фотографиям (снимок с камеры или файл из галереи) и показывает историю отчётов.

Вход не нужен: приложение обращается к открытому разделу API `/api/m/*` и хранит всё на сервере. Система сама находит эталон, считает масштаб, выделяет образец, считает площадь, сравнивает два снимка, проверяет результат и сохраняет версию отчёта.

## Сборка

Нужны Flutter 3.22+ и Android SDK.

```
tools\setup.bat
tools\build.bat http://АДРЕС_СЕРВЕРА:47310
```

На Linux и macOS те же команды в `tools/setup.sh` и `tools/build.sh`.

Готовый файл: `build/app/outputs/flutter-apk/app-release.apk`.

Адрес сервера задаётся при сборке (`--dart-define=API_URL=...`). Если на сервере включён `MOBILE_KEY`, ключ передаётся так же: `--dart-define=API_KEY=...`.

Сервер работает по HTTP без домена, поэтому в манифесте включён `usesCleartextTraffic`.

## Экраны

- Новый отчёт: до двух фото (камера или галерея), необязательное название, кнопка «Составить отчёт».
- История: список отчётов, свайп влево удаляет.
- Отчёт: превью с контурами, площадь и периметр, сравнение двух снимков, список проверок, выводы, PDF, CSV и архив.
